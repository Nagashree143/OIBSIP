# To-Do Web App

## Project Overview

This project is a responsive To-Do Web Application developed using HTML5, CSS3, and JavaScript.

The application allows users to create, manage, edit, complete, and delete tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Edit existing tasks
- Delete tasks
- Separate pending and completed task lists
- Pending task count
- Completed task count
- Total task count
- LocalStorage support
- Empty-state messages
- Responsive design

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The To-Do Web App will open in the browser.
