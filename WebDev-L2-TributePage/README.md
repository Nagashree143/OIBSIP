# Tribute Page - Dr. A. P. J. Abdul Kalam

## Project Overview

This project is a responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, former President of India and aerospace scientist.

The webpage presents his biography, important milestones, achievements, and inspirational quote in a simple and attractive design.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive web design
- Dr. A. P. J. Abdul Kalam image
- Biography section
- Important milestones timeline
- Inspirational quote
- Multiple background sections
- Different font styles
- Mobile responsive layout
- Clean and simple user interface

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The Tribute Page will open in the browser.
