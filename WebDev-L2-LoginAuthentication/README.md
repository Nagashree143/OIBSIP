# Login Authentication System

## Project Overview

This project is a Login Authentication System developed using HTML5, CSS3, and JavaScript.

The application allows users to register an account, validate their information, securely hash their password using SHA-256, log in, access a dashboard, and log out.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API
- LocalStorage

## Features

- User registration
- Full name validation
- Email validation
- Password validation
- Confirm password validation
- Duplicate email checking
- SHA-256 password hashing
- User login
- Protected dashboard
- Logout functionality
- Login session using LocalStorage
- Responsive design
- User-friendly interface

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The Login Authentication System will open in the browser.
6. Register a new account.
7. Login using the registered email and password.
8. Access the dashboard and test the logout button.
