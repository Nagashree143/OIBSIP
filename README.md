## 📌 Tasks Completed

I completed all four tasks assigned under the **Web Development and Designing - Level 2** internship.

### Task 1 - Calculator

A responsive web-based calculator developed using HTML5, CSS3, and JavaScript.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear functionality
- Backspace functionality
- Equals operation
- Operator chaining
- Division-by-zero handling
- Responsive user interface

**Technologies:** HTML5, CSS3, JavaScript, CSS Grid, DOM Manipulation

---

### Task 2 - Tribute Page

A responsive tribute webpage dedicated to **Dr. A. P. J. Abdul Kalam**.

The webpage presents information about his life, achievements, contributions, and inspirational thoughts.

**Features:**
- Biography section
- Image
- Timeline
- Achievements
- Contributions
- Inspirational quote
- Multiple background sections
- Different fonts
- Responsive design

**Technologies:** HTML5, CSS3

---

### Task 3 - To-Do Web App

An interactive task management web application that allows users to create and manage their daily tasks.

**Features:**
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Pending task list
- Completed task list
- Task counters
- Empty-state messages
- Local Storage support
- Responsive interface

**Technologies:** HTML5, CSS3, JavaScript, DOM Manipulation, Local Storage

---

### Task 4 - Login Authentication System

A frontend-based login authentication system developed using HTML5, CSS3, and JavaScript.

**Features:**
- User registration
- Form validation
- Email validation
- Password validation
- Duplicate email checking
- Password hashing using Web Crypto API
- User login
- Authentication validation
- Protected dashboard
- Logout functionality
- Local Storage
- Responsive interface

**Technologies:** HTML5, CSS3, JavaScript, Web Crypto API, Local Storage

> **Security Note:** This project is an internship frontend demonstration. A production authentication system should use a secure backend, server-side password hashing, database storage, HTTPS, and secure sessions or tokens.
